# محاكي فيزياء المنجنيق — Catapult / Trebuchet Physics Simulator

تطبيق ويب تعليمي عربي (RTL) يحاكي منجنيقًا ذا ثقل موازن (Counterweight Trebuchet) في مشهد جانبي ثنائي الأبعاد، بمحرك حسابات فيزيائية حقيقي وفق قوانين الميكانيكا الكلاسيكية — لا حركة مرسومة مسبقًا ولا نتائج مُخمَّنة.

## التشغيل

لا يحتاج التطبيق إلى أي خادم أو أدوات بناء:

- افتح `index.html` مباشرة في المتصفح، **أو**
- شغّل خادمًا محليًا: `python3 -m http.server` ثم افتح `http://localhost:8000`.

## المزايا

- **محرك فيزيائي**: معادلات لاغرانج حتى 3 درجات حرية (`M(q)·q̈ = f(q,q̇)`) تشمل الذراع ذا الكتلة (مبرهنة المحور الموازي)، الثقل المثبت أو **المتأرجح**، و**المقلاع (Sling)**، مع الاحتكاك والتخميد.
- **نمط الذراع العائمة (Floating Arm Trebuchet)**: محور يتدحرج على سكة أفقية وثقل يسقط رأسيًا خالصًا في قناة (`x_axle = −Lc·cosθ`) — مصفوفة كتلة متغيرة مع الوضع `T = ½A(θ)θ̇²` تُحل بحدود كريستوفل عددية يتحقق منها فحص حفظ الطاقة (انحراف ~10⁻⁹%).
- **تكامل عددي**: Runge-Kutta 4 (افتراضي) أو أويلر شبه الضمني، مع استيفاء دقيق للحظة التحرير ونقطة السقوط.
- **حركة المقذوفات** بعد التحرير مع مقاومة هواء اختيارية `Fd = ½ρCdAv²` ورياح مساعدة/معاكسة.
- **ميزان طاقة** لحظي (وضع/حركة/دوران/مفقودة) وفحص حفظ الطاقة لاكتشاف الأخطاء العددية، ونسبة الكفاءة.
- **وضع التحقق الفيزيائي**: مقارنة المدى وزمن الطيران العدديين بالحل التحليلي وعرض نسبة الخطأ.
- **مُحسِّن الكفاءة**: زر «حسّن إعداداتي» يبدأ من قيم المستخدم الحالية ويبحث بالنزول الإحداثي الجشع عبر مئات التشغيلات الفعلية للمحاكاة عن التوليفة الأعلى كفاءة (مع رفض التوليفات المتحطمة إنشائيًا أو عديمة المدى)، ثم يعرض المقترح والتعديلات ولا يطبّق إلا بموافقة المستخدم.
- **جدار هدف قابل للهدم (وضع الحصار) 🧱**: الهدف جدار بمادة (خشب/طوب/حجر/خرسانة) وسماكة وارتفاع يتحكم بها المستخدم. عند الاصطدام تُعرض قوة القذيفة (KE = ½mv²، الزخم، القوة المتوسطة F = KE/d بانسحاق معلَن، الضغط)، ويهدم المكوّنُ العمودي `KE⊥ = ½m·vx²` الجدارَ تدريجيًا مقابل سعة هدم `E = u·t·A` — ضرر تراكمي عبر الرميات مع عداد قذائف وتقدير المتبقي، شقوق مرئية، وانهيار بركام تمر بعده القذائف عبر الثغرة، والإصابات دون العتبة ترتد بلا ضرر، والعبور فوق الارتفاع يفوّت الجدار.
- **أقفال التثبيت 🔒**: بجانب كل معامل قابل للتحسين (وبجوار مفتاحي المقلاع والثقل المتأرجح — مقفولين افتراضيًا) زر قفل يثبّت القيمة، فيجيب المُحسِّن عن: «ما أقصى كفاءة ممكنة في ظل هذه القيم المثبتة؟» — مثلًا تثبيت طول المقلاع الذي اخترته ومعرفة أقصى كفاءة يمكن بلوغها معه.
- **تحليل التحطم الواقعي**: إجهاد الانحناء الديناميكي على الذراع الخشبي `σ = 6M/(b·h²)` مقارنةً بمعامل تمزق الخشب MOR (بلوط/دردار/صنوبر/شوح…) مع معامل أمان، وشد حبل المقلاع `T = Mp·(a⃗−g⃗)·û` مقابل قوة قطع القنب `F = σt·π·d²/4` — يتحطم الذراع فعليًا في المحاكاة أو ينقطع الحبل فيتحرر المقذوف مبكرًا، مع مخطط إجهاد/زمن وخط حد الكسر.
- **واجهة كاملة**: منزلقات + حقول رقمية لكل متغير بوحدات SI، هدف قابل للتحديد، عرض القوى، 7 رسوم بيانية حية، جدول مقارنة حتى 5 سيناريوهات مع عرض مسارَي تجربتين، وقسم «كيف تم حساب النتيجة؟».

## بنية الكود

| الملف | الدور |
|---|---|
| `js/physics/integrator.js` | مكاملا RK4 وأويلر شبه الضمني + حل الجمل الخطية |
| `js/physics/trebuchet.js` | نموذج المنجنيق: العزوم، عزم القصور، معادلات لاغرانج، الهندسة |
| `js/physics/projectile.js` | حركة المقذوفات، السحب الهوائي، كشف الاصطدام بالأرض |
| `js/physics/energy.js` | ميزان الطاقة والكفاءة |
| `js/physics/validation.js` | المقارنة بالحل التحليلي |
| `js/physics/structure.js` | التحليل الإنشائي: مواد الخشب، إجهاد الانحناء، شد الحبل، معايير الكسر |
| `js/physics/wall.js` | جدار الهدف: مواد البناء، مقاييس الاصطدام، سعة الهدم والضرر |
| `js/simulation.js` | منسّق التجربة (طور الذراع ← التحرير ← الطيران) والنتائج |
| `js/optimizer.js` | مُحسِّن الكفاءة: نزول إحداثي جشع على تشغيلات فعلية للمحاكاة |
| `js/renderer.js` | رسم المشهد على Canvas (RTL) وطبقة القوى |
| `js/charts.js` | مكوّن رسوم بيانية خفيف على Canvas |
| `js/ui.js` | لوحة التحكم والنتائج والتحذيرات |
| `js/scenarios.js` | حفظ ومقارنة السيناريوهات |
| `js/main.js` | الربط وحلقة العرض |

> ⚠ هذه محاكاة تعليمية — القيم ليست توصيات هندسية لبناء فعلي.

## العرض ثلاثي الأبعاد 🌄

صفحة `3d.html` تعرض المحاكاة في بيئة مفتوحة ثلاثية الأبعاد (Three.js مضمّنة محليًا): أرض ممتدة وسماء وتلال وإضاءة شمسية بظلال، كاميرا حرة (سحب للدوران/عجلة للتقريب) مع تتبع تلقائي للمقذوف، وهيكل ثلاثي الأبعاد لكل الأنماط (المحور الثابت والذراع العائمة) والجدار والهدف — وكل الحركة من نفس محرك الفيزياء وإطاراته المحسوبة، العرض لا يغيّر الديناميكا إطلاقًا.
