# محاكي فيزياء المنجنيق — Catapult / Trebuchet Physics Simulator

تطبيق ويب تعليمي عربي (RTL) يحاكي منجنيقًا ذا ثقل موازن (Counterweight Trebuchet) في مشهد جانبي ثنائي الأبعاد، بمحرك حسابات فيزيائية حقيقي وفق قوانين الميكانيكا الكلاسيكية — لا حركة مرسومة مسبقًا ولا نتائج مُخمَّنة.

## التشغيل

لا يحتاج التطبيق إلى أي خادم أو أدوات بناء:

- افتح `index.html` مباشرة في المتصفح، **أو**
- شغّل خادمًا محليًا: `python3 -m http.server` ثم افتح `http://localhost:8000`.

## المزايا

- **محرك فيزيائي**: معادلات لاغرانج حتى 3 درجات حرية (`M(q)·q̈ = f(q,q̇)`) تشمل الذراع ذا الكتلة (مبرهنة المحور الموازي)، الثقل المثبت أو **المتأرجح**، و**المقلاع (Sling)**، مع الاحتكاك والتخميد.
- **تكامل عددي**: Runge-Kutta 4 (افتراضي) أو أويلر شبه الضمني، مع استيفاء دقيق للحظة التحرير ونقطة السقوط.
- **حركة المقذوفات** بعد التحرير مع مقاومة هواء اختيارية `Fd = ½ρCdAv²` ورياح مساعدة/معاكسة.
- **ميزان طاقة** لحظي (وضع/حركة/دوران/مفقودة) وفحص حفظ الطاقة لاكتشاف الأخطاء العددية، ونسبة الكفاءة.
- **وضع التحقق الفيزيائي**: مقارنة المدى وزمن الطيران العدديين بالحل التحليلي وعرض نسبة الخطأ.
- **واجهة كاملة**: منزلقات + حقول رقمية لكل متغير بوحدات SI، هدف قابل للتحديد، عرض القوى، 7 رسوم بيانية حية، جدول مقارنة حتى 5 سيناريوهات مع عرض مسارَي تجربتين، وقسم «كيف تم حساب النتيجة؟».

## بنية الكود

| الملف | الدور |
|---|---|
| `js/physics/integrator.js` | مكاملا RK4 وأويلر شبه الضمني + حل الجمل الخطية |
| `js/physics/trebuchet.js` | نموذج المنجنيق: العزوم، عزم القصور، معادلات لاغرانج، الهندسة |
| `js/physics/projectile.js` | حركة المقذوفات، السحب الهوائي، كشف الاصطدام بالأرض |
| `js/physics/energy.js` | ميزان الطاقة والكفاءة |
| `js/physics/validation.js` | المقارنة بالحل التحليلي |
| `js/simulation.js` | منسّق التجربة (طور الذراع ← التحرير ← الطيران) والنتائج |
| `js/renderer.js` | رسم المشهد على Canvas (RTL) وطبقة القوى |
| `js/charts.js` | مكوّن رسوم بيانية خفيف على Canvas |
| `js/ui.js` | لوحة التحكم والنتائج والتحذيرات |
| `js/scenarios.js` | حفظ ومقارنة السيناريوهات |
| `js/main.js` | الربط وحلقة العرض |

> ⚠ هذه محاكاة تعليمية — القيم ليست توصيات هندسية لبناء فعلي.
